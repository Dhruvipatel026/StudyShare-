
# StudyShare

Computer Engineering Academic Resource Portal

## About
StudyShare helps students find and share semester-wise study materials.

## Features
- Student registration and login
- Upload and download study resources
- Admin approval of resources
- Star ratings
- Student note requests
- Resource search and filtering

## Technologies
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Local Setup
Run the project using WAMP and import the project database into phpMyAdmin.
